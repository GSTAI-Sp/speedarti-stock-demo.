# SpeedArti — Stock — Démo publique

Ce dépôt contient uniquement la démonstration publique du module Stock SpeedArti.

## Contenu

- interface de démonstration ;
- fichiers statiques compilés nécessaires au fonctionnement ;
- styles publics ;
- données de démonstration fictives ;
- workflow GitHub Pages.

## Ne contient pas

- code source TypeScript de développement ;
- tests internes ;
- architecture détaillée ;
- contrats d'intégration production ;
- plans de migration ;
- documentation de reprise Anne-Sophie ;
- base centrale Ángel ;
- données SpeedArti de production ;
- secrets ou identifiants.

## Production

Cette démo n'est pas raccordée à SpeedArti production.

L'intégration réelle dans SpeedArti V2 et dans Ángel central relève exclusivement d'Anne-Sophie.
